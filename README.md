# Digital Frequency

Plataforma inteligente para gerenciamento de frequência escolar.

## Objetivo

Substituir listas de presença em papel por um processo digital com QR Code, geolocalização e relatórios em tempo real.

## Tecnologias

- Next.js
- NestJS
- PostgreSQL
- Prisma
- Docker
- Turborepo
